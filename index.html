How to demonstrate Scalar's API client

These are live HTTP requests to a public API, not simulated responses. Follow the sequence during your presentation.

01
Select an endpointScroll to the API reference, then select GET /jokes/categories.
02
Open Test RequestClick Scalar's Test Request action to open the interactive API client.
03
Send the requestKeep the public server selected and click Send Request. No authentication is required.
04
Inspect the responseExplain the HTTP status, headers and JSON array. Repeat with a dev category or search keyword.
